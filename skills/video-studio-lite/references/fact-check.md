# 事实核查

讲知识的视频不能有常识性错误。写完稿子、渲染之前，**必须**起一个独立的核查 agent 审稿：写稿的人很难发现自己的口径问题。比如"暂停申购"被写成"限购 2 元"，"某月以来最多"被写成"某年以来最多"，都是核查 agent 查出来的。

## 怎么起核查 agent

用 Agent 工具（general-purpose，后台运行），把下面的提示词填好发出去。核查期间可以并行做配音和版式，但核查结论回来之前不要出最终片。

```
You are an independent, adversarial fact-checker for a Chinese explainer video
(beginner audience). Today is <日期>. Topic: <选题>.

Input: <episode_dir>/episode.py — every s.beat('...') string is narration; strings in
txt()/box()/title()/mindmap()/table()/cover() and chart data are on-screen text.
Data the script was built from: <episode_dir>/data/*.json. Read-only: do not edit files.

Check every factual claim (narration AND on-screen text, chart labels, footnotes,
table cells, mock-ups). Verdict per claim: correct / inaccurate / misleading /
unverifiable. Prefer primary sources (official announcements, regulators, exchanges,
the original paper or dataset, reputable news) and recompute numbers yourself.
Apply the general checklist in <本 skill 目录>/references/fact-check.md
and any topic section there that fits.

Output (Chinese): 1) prioritized problems — slide id + quoted text, verdict, evidence
with URL and correct figure, a ready-to-paste replacement (same length, colloquial);
2) table of claims checked and found correct, with sources; 3) new pitfalls worth
adding to the checklist.
```

`<episode_dir>` 是 `~/VideoStudio/episodes/<名字>`（设了 `STUDIO_HOME` 就在它下面），`<本 skill 目录>` 填这个 skill 的实际路径，都写成绝对路径。

核查报告回来后：逐条改 `episode.py`（字幕和画面一起改），重新 `check`，再出片。新发现的坑补到下面的清单里。

## 通用清单

1. **时效**：会变的数据（价格、政策、排名、状态）写明"截至 X 月 X 日"，发布当天再刷新一次。举例优先用最近发生的事。
2. **最高级**（"以来最多""首次""最大"）：必须拿完整历史序列核对，起点差一个月结论就可能不成立。
3. **极值和典型值**：开头抓眼球的数字如果是最高的那个，要说"最高"，或者直接给区间（"贵了一成多，最高 16%"）。
4. **区间**："过去 N 年"写清起止年份；图上"今年至今"要和完整年份区分开。
5. **口径一致**：拿来比较的两个数，统计口径、计价单位、时间点要一致；不一致就在画面注明。
6. **规则措辞**：带上限定词——"新纳入时""一般""最晚"。省掉限定词，常常就从简化变成了错误。
7. **因果**：别把相关说成因果，也别把"其中一个原因"说成"就是因为"。
8. **机制解释**要能解释现象本身，不能只解释现象的一部分。
9. **自动抓取的字段**：状态和数字分开判断，解析完人工抽查几条。字段里括号中的数字可能是旧值（见下面金融部分第 1 条）。
10. **名称和身份**：机构、产品、指数、人物的名字和历史（更名、转型、成立日期）分开核对。
11. **术语**：专业名词的定义、中英文对应、缩写全称要核对；给初学者的简化说法不能和定义冲突。
12. **引用原话**：标「有删减」就只能删不能改；改了语序或去掉「可能」这类限定词，要标「整理过」。用「」引某人原话，要和原始记录逐字对上；转述就别加引号。

## 讲自己的工具、流程的片子

1. **例子要有记录**：说"踩过的坑"，得在 lint、审稿报告或手册经验区里找得到。预防性的修正（比如提前写好的 `pron`）不能说成「念错过」。
2. **说清是哪道检查抓到的**：多音字检查只比对多音字的读音，数字转成读法时的错误（「12年」念成「一二年」）它抓不到，要在 `lint.txt` 和成片里自己听。
3. **功劳别归错**：混音、配乐、音效是引擎代码合成的，ffmpeg 只负责编码 MP4；配音是代码交给在线语音服务合成的，不是代码自己发声。分清仓库自己的代码和它调用的外部工具、服务。
4. **画面上的代码要能跑**：必填参数不能省；写「大概长这样」可以省略坐标细节，但不能写成错误用法。
5. **号称「真实数据」的演示**：出片前确认已经换成真值，不是占位符。
6. **「独立 agent」**是同一个模型新开的上下文，不等于换了一家模型，别说混。
7. **汇总统计别说成「每一个都」**：平均值没变，不等于每一项都没变。用修复本身的标准量修复效果，要在画面上写清量法。
8. **「每秒 N 帧」和「截多少张图」分开说**：相同的连续帧只截一次。字幕在哪里切由标点、分词和行宽决定，每个字的时间只决定每条什么时候出来。音效只配给有默认音效的元素类型（卡片、框、胶囊、柱子……），不是每个元素。
9. **演示数据由事后脚本生成时**，写清顺序：最后一次 `check` → 脚本 → `all`；前面任何一页口播改了都要重跑。
10. **文档里的说法比代码更绝时，以代码为准**，顺手把文档改对。
11. **判定线别贴着对照组的底噪**：门限一变结论就变的指标，上画面前换两三个门限试试，或者用另一种量法交叉验证。
12. **同一个指标，前后两期量法要一致**；不一致就在画面上注明量法。
13. **「N 个」要分清是有几个，还是量了几次**（39 个逗号 × 2 遍 = 78 次）。
14. **归因先查代码和提交记录里写的原因**：工具自己的参数也有份的话，别全推给素材或模型。猜的原因要核实，不能直接当结论。
15. **写稿前先读上一期的核查报告**，被改掉的说法别原样写回来。画面上的示意动画（切句、切字幕）也要符合引擎的真实规则。
16. **场景 JS 里也会藏手填的数字**：一律从 data 或引擎常量传进去。改口播时保留 `S.word()` / `s.sound(word=)` 用到的关键词（找不到时 `S.word` 退回句首，`s.sound` 直接报错）。

## 推广自家产品

1. **引用 AI 或用户说的话，先按画面上的数字复算一遍**。片子要是在夸它「会算账」，被引用的那句必须算得对；算错了，就如实点出来。
2. **叫观众「去搜 X」之前，自己先真搜一次**。新域名、单页应用可能根本搜不到；英文名还可能撞上不相关甚至危险的内容。最稳的是直接给网址。
3. **模拟数据的运行设置，和用户实际的默认设置分开写**。比如模拟时打满 60 轮、用户默认打得更短，画面上要写清楚「打满 60 轮」。
4. **「爆火」「全网都在玩」这类说法**：用在自家带付费的产品上，《广告法》和反不正当竞争法都管虚假宣传。再加上不表明身份、画面上有站外网址，风险叠在一起最大。用户坚持要用，就照用，但要把风险和等长的替换说法一起交给用户。
5. **并列对比两个案例**（「同样首付不够」）之前，先核对两边条件是否真的可比：一个差三万，一个差八千，就不能说「同样」。
6. **截图上有什么，口播就说什么**：截图里只有负债、没有工资，就别说「上面写着工资」。

## 金融选题补充

1. **申购状态**：分清"暂停申购"和"限大额"。数据源字段写成 `暂停申购(单日投资上限X元)` 时，括号里的 X 可能是暂停前的旧限额，当前其实是**全面暂停**。顺手核对定投是否也暂停。
2. **渠道和份额**：直销和代销限额可能不同；A/C/E 类、人民币/美元份额分开限。画面注明口径，比如"代销渠道"。
3. **价格指数 vs 全收益**：年化收益要说清是否含分红；拿基金净值（含分红、扣费、含汇率）和指数比，要交代差异。
4. **计价货币**：美元份额和人民币份额收益差 ≈ 汇率变化，持有的是同一篮子资产，换成同一种货币后几乎一样。别让观众以为"买美元份额更赚钱"。
5. **跟踪标的**：纳指科技 ≠ 纳指100，纳斯达克综合 ≠ 纳斯达克100。比较溢价或跌幅时，用这只基金自己的指数或净值。
6. **溢价口径**：美股 QDII-ETF 用"收盘价 ÷ 前一日净值 − 1"或 IOPV；不要用当日净值（那是当晚美股的结果）。
7. **指数规则**：比如标普 500 只要求**新纳入**的公司盈利（最近一季和最近四季合计为正），已在指数里的公司亏损不会被剔除。
8. **到账时间**：确认日和到账日分开讲，以基金公司官方口径为准（QDII 一般 T+2 确认，赎回 T+4~T+10 到账）。
9. **表达边界**：核查重点是讲解有没有保留具体条件、算账假设和风险，不能用一句通用声明代替。声明放不放进画面、要不要口播，按用户和发布平台的要求。
10. **穿透金额的分母**：把基金持有市值乘行业权重时，行业比例必须先统一为占基金净资产。原表若占股票市值，先乘股票占基金净资产的比例；总资产口径也需转换。用历史披露权重估算当前金额时说明估算边界；联接基金还要考虑目标基金比例、直接持仓与现金。
