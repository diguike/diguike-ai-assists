# 风格和主题参数

默认风格叫 `shouxie`（手写）：白底、手写感的字、橙色重点、黄底封面，元素像对着 Keynote 边讲边点一样逐个出现。新视频不管讲什么，默认都用它；只有用户要求时才改主题。要换风格时看下面的「换风格」：8 套预设，配色、字体、动效三类部件可以自由组合。

**只换风格改不了「像 PPT」**：预设只换配色、字体和入场方式，版式和「说一句出一个元素」的结构不变。用户要「不是 PPT 的、更丝滑连贯的」「科技原理的动画拆解」「情感向」时，换的是**片种**：原理动画（`playbooks/mechanism.md`，配「瓷光」）或情感短片（`playbooks/film.md`，配「暖光」）。

## 默认风格

| 元素 | 规范 |
|---|---|
| 画布 | 1920×1080 横屏，白底；封面和片尾用黄底 `#FFDA31` |
| 字体 | 霞鹜文楷（`assets/fonts/WenKaiGB-Medium.ttf`，CSS family `WenKai GB`），随 skill 带着走，不依赖系统安装；是常用字子集，生僻字会退回系统黑体。数字、图表刻度、字幕用苹方（Mac）或微软雅黑（Windows） |
| 重点色 | 橙 `#F8A000`，HTML 里写 `<em>`；深橙 `#D48800` 用于浅底上的标签 |
| 图表配色 | `T.secondary` 蓝 `#2F9BEF`（第一序列）、`T.primary` 橙（第二序列）、`T.muted` 灰（参照项） |
| 表格 | 蓝表头 `#48B0F8` 白字；强调行用黄 `#FCEB86` 高亮 |
| 思维导图 | 左侧橙色标签 → 细黑连线 → 橙框（4px）→ 右侧说明，最常用的版式 |
| 流程 | 橙色圆圈 + 箭头 |
| 标题 | 居中、橙色；问句标题用 `question()`（设了吉祥物时前面带上吉祥物） |
| 高亮框 | 橙色描边框画出来圈重点（`s.mark()`），最好用的强调动作 |
| 水印 | 默认没有 |
| 字幕 | 底部橙色粗体，白描边；每条最多 17 字（竖屏 14 字），不带标点；封面色底的页自动换深灰 |
| 封面 | 封面色 + 系列名（默认空）+ 白色标题框（带阴影）；主标题默认 116 设计像素、500 字重、1.2px 同色描边，系列名 88px/500 |
| 片尾 | `end_slide()`：黄底「下期见」，口播一句「这期就到这里，我们下期见。」；用 `end_card` / `outro` 换成自己的 |

### 自己的频道名、吉祥物

默认没有水印、系列名和吉祥物，片尾只有一句通用的「下期见」。用户有自己的频道或系列时，在 `episode.py` 顶部写：

```python
use_theme(watermark='我的频道', series='系列名', end_card='下期见', outro=['关注我，下期见。'])
```

想要吉祥物：把图片放进这一期的 `assets/`，再加 `mascot='xxx.png'`。封面、问句标题、片尾都会带上它。一个系列定下来以后，可以把这些写进一套自己的预设（见下面「主题参数」最后一段），每期只写 `use_theme('<名字>')`。

### 封面标题

`cover()` 和 `cover_page()` 共用主题的 `cover_type`，横竖版按画布面积缩放。长标题先缩短文案、重新断行，检查原尺寸和手机缩略图，不要为了塞下长标题把字改小。可以用 `box_font / box_weight / box_stroke / series_font / series_weight` 逐项覆盖。文楷只有一个字重，500 配轻描边比直接加粗更好控制笔画内空。

## 动画

默认的动效预设叫 `keynote`：

- 文字默认打字机效果（每秒约 15 字，带光标）。
- 框和卡片淡入，圆圈和胶囊弹出，连线、箭头、高亮框描边画出，表格行从左往右擦出，柱子长出来。
- 每个元素都挂在某句口播上：这句话开始说，元素才出现，相当于对着 Keynote 边讲边点。
- 换页 0.35 秒淡入淡出。

其他动效、转场、镜头推近见下面的「动画、转场、镜头」；元素出现以后的动作（强调、退场、移动、聚焦、光标）和组合配方见 `atoms.md`。

## 口播

- Edge TTS 合成，默认男声 `zh-CN-YunxiNeural`、语速 `+22%`（`META['voice']` / `META['rate']` 可改；女声如 `zh-CN-XiaoxiaoNeural`）。目标约 6 字/秒，`plan` 会打印说话时的实际字/秒。
- 写成口语，像跟朋友聊天；一句别太长，长句拆成两拍。
- 开头：一个具体的现象或痛点抛问题，然后"今天这期，就把……一次讲清楚"。
- 常用句式："大家可以看这张图"、"很多朋友会问"、"简单来说"、"举个例子"、"我们来算一笔账"、"所以记住一句话"。
- 结构：是什么 → 历史/现状 → 怎么做 → 为什么（机制）→ 风险或代价 → 几点实操建议 → 总结一句话。
- 结尾：`end_slide()` 念主题的 `outro`（默认一句「这期就到这里，我们下期见。」）；不想要片尾就不加这一页，用最后一页的总结句收尾。
- 讲投资、健康、法律这类话题：用讲解中的具体条件、假设和风险说明边界，不要用一句通用免责声明代替。声明要不要印在画面上、要不要口播，按用户和发布平台的要求来。

## 换风格

一套风格 = **配色**（palette）× **字体**（typeset）× **动效**（motion），再加上画幅、字幕和品牌。预设就是挑好的一组搭配，部件也能单独换。

```bash
studio styles                      # 列出预设和部件
studio styles gallery              # 同一份样片在每套预设下各出一排图 -> ~/VideoStudio/work/styles/gallery.jpg
studio styles silent yedu          # 样片动起来（无配音，10 秒左右出片）-> ~/VideoStudio/work/styles/yedu.mp4
studio styles silent shouxie motion=snappy palette=night   # 试一个组合
studio new 某期 '标题' --style zhiben    # 新建时直接套预设
```

### 什么时候换，怎么选

- 用户没提风格：不换，用默认。
- 用户要别的风格，或者开新系列：先跑 `studio styles gallery`，把图给用户看；需要看动效再跑 `styles silent`。然后给 2～3 个方案，每个一句话说清**画面的核心感觉**（例如"黑板课堂：老师边讲边写"、"纸本：读书笔记的安静"），不要只是同一套版式换三种颜色。用户选定再写进 `use_theme()`。
- 上一个系列的风格不要默认带到新系列。一个系列定下来以后，就固定用那一套。
- 用户说"你挑一个"时，按题材挑一套，在交付时说明理由，并附上 gallery 方便用户另选。
- 讲工具、流程、技术的片子，别默认用深色底（`yedu` 夜读）：容易显得暗沉，像只换了配色的 PPT。优先用原理动画片种加 `ciguang` 瓷光（浅底）。
- 瓷光这类"精致"的浅色风格，要点是：暖白底而不是冷灰；卡片白底、圆角 16px（小件 8–12px）、1px 半透明细描边、淡而长的阴影，不要 28px 的大圆角，也不要只靠大片模糊阴影浮起来；描线 1.25–2px；小标签 400 字重、灰、字间距 1.5px；示意图用细线面积图、圆环、浅色底加 1px 色边，不要大块纯色方块和圆饼；颜色一律用主题变量，不写死色值。

### 预设（`use_theme('名字')`）

| 预设 | 组合 | 适合 |
|---|---|---|
| `shouxie` 手写（默认） | 自带配色 + 文楷手写感 + keynote | 讲解、科普，对着 Keynote 边讲边点的感觉 |
| `heiban` 黑板课堂 | chalk + hand + keynote | 保留手写、逐字写出的讲课感，换成黑板 |
| `zhiben` 纸本 | paper + song + calm | 读书、历史、人文 |
| `yedu` 夜读 | night + heavy + snappy | 科技、数据、复盘 |
| `nuanyang` 暖阳 | peach + kai + calm | 故事、情感、亲子 |
| `heibai` 黑白红 | mono + heavy + editorial | 观点、评论 |
| `ciguang` 瓷光 | porcelain + lab + fluid，每页轻微缓推 | 原理动画：科技原理、产品和流程拆解。暖白底、白卡片（16px 圆角、1px 细描边、淡阴影）、钴蓝信号色、细黑字，一切慢慢落定 |
| `nuanguang` 暖光 | amber + serif + cinema，颗粒、暗角、2.39 遮幅、缓推 | 情感短片：品牌、回忆、心里话。暖色光影、细宋大字，字一行行浮现 |

外观预设只管配色、字体、动效，不改画幅和品牌：系列名、水印、吉祥物还是默认的（都为空），片尾还是默认的「下期见」，需要时一起写（`series=`、`watermark=`、`end_card=`、`outro=`、`mascot=`）。

### 部件

| 配色 `palette=` | |
|---|---|
| `sunny` | 默认风格的颜色：白底、橙重点、黄封面 |
| `chalk` | 墨绿黑板、粉笔白字、黄粉笔重点 |
| `paper` | 米色纸、墨黑字、朱红重点 |
| `night` | 深蓝黑底、奶白字、琥珀重点 |
| `ocean` | 饱和蓝底、白字、明黄重点 |
| `mint` | 浅薄荷底、深绿字、翠绿重点 |
| `peach` | 暖白底、可可色字、珊瑚橙重点 |
| `mono` | 白底黑字一抹红，黑封面 |
| `porcelain` | 瓷白底、墨黑字、钴蓝信号、一点珊瑚和青绿：产品原理的干净 |
| `amber` | 暖象牙底、深可可字、铜色光、黄昏蓝：有光源的情绪 |

| 字体 `typeset=` | 标题 / 正文 |
|---|---|
| `hand` | 全片文楷手写感（默认） |
| `heavy` | 系统最粗的黑体 / 黑体中粗（没有随包带 17MB 的思源黑 Heavy） |
| `song` | 宋体特粗 / 黑体 |
| `kai` | 霞鹜文楷 / 霞鹜文楷 |
| `smiley` | 得意黑斜体（随包带）/ 黑体中粗 |
| `clean` | 黑体粗 / 黑体 |
| `lab` | 黑体中粗 / 黑体常规，字重轻、留白多 |
| `serif` | 宋体细体 / 黑体细体，字距放开 |

表里的"黑体"在 Mac 上是苹方，在 Windows 上自动退到微软雅黑；"宋体"在 Mac 上是宋体-简，在 Windows 上退到宋体。所以同一期视频在两台电脑上出图，字形和字宽会略有差别，排版以当台电脑的 `layout.txt` 为准。不管哪套字体，`hand()` 批注都用文楷，数字、刻度、字幕用黑体。

| 动效 `motion=` | 文字 / 标题 / 框 | 换页 |
|---|---|---|
| `keynote` | 逐字打出 / 淡入 / 淡入，胶囊弹出 | 淡入淡出 0.35 秒（默认） |
| `snappy` | 弹簧上浮 / 遮罩升起 / 弹出，整体快 10% | 横推 |
| `calm` | 由虚变实 / 遮罩升起 / 淡入，整体慢 30% | 淡入淡出 0.7 秒 |
| `bouncy` | 弹簧上浮 / 盖章砸下 / 盖章 | 缩放 |
| `editorial` | 遮罩升起 / 遮罩升起 / 从左擦出 | 擦除 |
| `fluid` | 慢慢落定（淡入、轻微上浮和对焦）/ 同 / 同 | 溶解 0.8 秒 |
| `cinema` | 比 fluid 更慢 1.7 倍 | 溶解 1.4 秒 |

组合写法：

```python
use_theme(palette='chalk')                        # 默认风格换成黑板配色，其余不变
use_theme('yedu', motion='keynote')               # 夜读的颜色和字体，动画还是逐字打出
use_theme('zhiben', primary='#2D5F8B', trans='push', series='读书笔记', watermark='我的频道 · 读书笔记')
```

单独的颜色参数优先于 palette。做一套长期用的新预设：在 `themes/` 下新建 `<名字>.json`，写 `name`、`desc` 和 `palette` / `typeset` / `motion`（或完整的 `colors`）；要加新配色、新字体组、新动效，就往 `themes/parts/` 里对应的文件加一项。

## 主题参数

在 `episode.py` 顶部、建任何一页之前调用：

```python
use_theme(primary='#2BA471', font_scale=1.1)          # 只改几项，其余保持默认
use_theme(size=(1080, 1920))                          # 竖屏 9:16（竖屏模板已经写好）
use_theme('mytheme')                                  # 用 themes/mytheme.json，没写的项继承默认
use_theme('mytheme', watermark=None)                  # 预设 + 单项覆盖
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `size` | `(1920, 1080)` | 画布。竖屏 `(1080, 1920)`，3:4 `(1080, 1440)`，方形 `(1080, 1080)`。版式坐标按画布写，换比例要重新排版（竖屏用竖屏模板） |
| `font_scale` | `1.0` | 所有字号乘这个系数，包括正文、框、表格、图表文字、字幕和封面 |
| `primary` | `#F8A000` | 主色：重点字、标题、框线、高亮框。浅底色、字幕色、深一档的标签色跟着自动算 |
| `secondary` | `#2F9BEF` | 第二色：图表第一序列 |
| `ink` / `muted` / `danger` | `#222` / `#9AA6B2` / `#E81808` | 正文色 / 次要灰 / 红叉、亏损 |
| `background` / `cover` | 白 / `#FFDA31` | 普通页底色 / 封面和片尾底色（`Slide(bg='cover')`） |
| `table_header` / `table_highlight` | `#48B0F8` / `#FCEB86` | 表头 / 强调行 |
| `primary_dark` / `tint` / `tint2` | 自动 | 想精确控制时再写 |
| `font_family` / `font_file` | `WenKai GB` / `fonts/WenKaiGB-Medium.ttf` | 换主字体：字体文件放进 `assets/fonts/`，两项一起改。注意字体许可证允许再分发 |
| `ui_font` | `PingFang SC` | 数字、刻度、字幕用的无衬线字体；Windows 上没有苹方时自动退到微软雅黑 |
| `sub_size` / `sub_color` / `sub_bottom` / `sub_max_chars` | 48 / 自动 / 自动 / 自动 | 字幕字号（按画布缩放）、颜色、离底边距离（竖屏自动抬到 20% 高度，避开平台按钮）、每条最多字数 |
| `mascot` | 无 | 吉祥物图片（`assets/` 下），`None` 不要 |
| `series` | 空 | 封面上的系列名 |
| `watermark` | 空 | 右下角水印 |
| `end_card` / `outro` | `下期见` / `['这期就到这里，我们下期见。']` | `end_slide()` 用的片尾字和口播 |
| `fonts` | 无 | 额外字体 `[{"family": ..., "file": "fonts/x.otf"}]`，比如主字体之外再加一个粗标题字体 |
| `css` | 无 | `themes/` 下的样式表，接在引擎样式后面，用来定义主题自己的版式类 |
| `palette` / `typeset` / `motion` | 无 / 无 / `keynote` | 三类部件，见上面「换风格」 |
| `grain` / `vignette` / `letterbox` / `drift` | 0 / 0 / 0 / 0 | 胶片颗粒（约 0.05～0.08）/ 暗角（约 0.2～0.3）/ 遮幅比例（如 2.39，字幕自动放进下边框）/ 每页缓推（约 0.02～0.03）。默认风格都不开 |
| `trans` / `trans_dur` | `fade` / 0.35 | 默认换页方式和时长（单页可以用 `Slide(trans=...)` 改） |
| `motion_speed` / `ease` / `type_cps` / `cam_dur` | 跟着 motion | 入场时长倍数 / 缓动曲线 / 打字速度（字/秒）/ 镜头移动秒数 |
| `card` `line` `soft` `rule` `grid` `axis` `label` `on_primary` `cover_ink` `marker` | 跟着配色 | 细分颜色：框和卡片底、连线、次要文字、表格线、图表网格、刻度、图表标签、主色上的字、封面上的字、荧光笔 |

图表里的颜色用 `T.primary / T.secondary / T.muted / T.danger`，网格、零线、刻度用 `T.grid / T.zero / T.axis`，换配色时图表会跟着变。

做一套长期用的新风格（比如带上自己的频道名、水印、吉祥物）：在 `themes/` 下建 `<名字>.json`，只写要改的项，然后 `use_theme('<名字>')`。

## 动画、转场、镜头

入场方式（`a=`）、元素出现后的动作、镜头推近和一镜到底、换页方式、音效，都在 `atoms.md`，那里也有组合配方。风格只决定**默认**怎么动：动效预设（`motion=`）给每类元素挑默认入场、缓动曲线、快慢和默认换页。

## 节奏和衔接

借鉴开源项目 onetake（做产品动效短片的 skill）总结的经验，按讲解视频的情况改过：

- **前后两页有联系时，用一个东西把它们接起来**：上一页的结论飞到下一页当标题（`magic`），从刚讲到的元素圆形展开下一页（`iris`）。观众看得出"这一页是从上一页长出来的"，就不像在翻 PPT。没有联系的两页，淡入淡出就够了，不要为了花哨乱用。
- **节奏要有变化**：每页长短一样、动画方式一样，会像节拍器。重点结论单独一页，放慢（`rate='+12%'`）、留停顿（`pause=`），用 `zoom` 或 `chime`；铺垫的内容可以快一点。
- **要有静止的时候**：结论出来以后让画面停一两秒，动作才显得有力。不要所有元素都在动，镜头也不要一直推。
- **音效宁少勿多**：每个元素都配声音会像老虎机。默认按类型自动配，快速连续出现的胶囊、柱子会自动沿音阶上行；嫌吵就给一部分元素 `sfx=None`。
- **画面上的数字都要有出处**：和事实核查一样，图表、大数字从 `data/*.json` 读，不手填。
- **出片前先看**：`studio <名字> silent [s05 s07]` 不等配音，按稿子估算时长出一段无声动画（样片约 10 秒），用来看转场和节奏；`stills` 会把出界、重叠、溢出、压字幕的元素写进 `work/layout.txt`。

## 字幕和配音分开写

- `beat(text=...)` 是字幕，也是默认的配音文本；`tts=` 只在念法必须和字面不同时才写。
- 数字代码（如 513100）、`T+0`、"2年"、百分比这些念法，引擎会自动处理，不用手写 `tts=`。
- 多音字：`check` 里的 `lint` 会把每个多音字所在的词和它几种读音的同音词分别合成、比对，结果写进 `lint.txt`（`MISMATCH` 是念错了，`unsure` 去听一下）。念错的用 `META['pron']` 按词换成同音字（如 `{'一行代码': '一航代码'}`），或者直接换个说法。`lint.txt` 还会列出跨词断开的分组（比如两个专有名词连在一起被念成别的词），在中间加个"的"或换个说法就好。
