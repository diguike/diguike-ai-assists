# 原子能力和组合配方

所有片种共用同一套积木。积木本身不带风格（颜色、字体跟着主题走），挑哪些、怎么组合由片种手册和这一期的概念决定。新做出一个好用的组合，就加到最后的「配方」里。

一页（`Slide`）由若干节拍（`s.beat`）组成。每个节拍的 show 列表里放两种东西：
- **元素 id**：元素第一次出现（入场）；
- **动作（cue）**：对已经在画面上的元素、或者对镜头做一件事。

两种东西用同样的时间写法：`'id'` 接在上一个后面，`('id', 0.6)` 从这句开始后 0.6 秒，`('id', '=')` 和上一个同时。

```python
s.beat('这就是答案', ['ans', (punch('ans'), 0.5), (shake(), 0.5)])
s.beat(None, [go('m', 900, 500), (click('m', target='btn'), 0.8)], dur=1.2)   # 没有口播的节拍
```

## 入场（元素的 `a=`）

| 写法 | 效果 | 什么时候用 |
|---|---|---|
| `type` | 逐字打出 | 讲课感、默认风格 `shouxie` 的入场 |
| `fade` / `pop` | 淡入上移 / 从小弹出 | 框、胶囊 |
| `rise` | 弹簧上浮，略过头再落回 | 利落的文字和卡片 |
| `mask` | 从自己下沿后面升起 | 标题、杂志感 |
| `zoom` | 从 1.5 倍盖章砸下 | 结论 |
| `blur` | 由虚变实 | 情绪、舒缓 |
| `slide` | 从左滑入 | 列表 |
| `count` | 数字从 0 滚上来 | `stat()` |
| `wipe` / `draw` / `growX` / `growY` | 擦出 / 描线 / 长出 | 表格行、线和箭头、柱子 |
| `cut` | 一帧出现 | 连击、硬切 |

不写 `a=` 时由风格的动效预设决定（style.md）。

**动态大字** `kinetic(id, 文字, y, size=, mode=)`：`words` 逐词弹起（用 `|` 分词，中文没分隔就逐字）、`letters` 逐字掉落并在落地时挤压（字标）、`lines` 逐行从遮罩里升起、`pops` 逐个弹出。**连击** `s.staccato(前缀, [词...], y, gap=)`：同一位置一个词硬切成下一个，返回 show 列表。

## 动作（cue）

| 写法 | 效果 | 什么时候用 |
|---|---|---|
| `pulse(id, amp=0.12)` | 鼓一下（amp 为负是按下去） | 提一下注意 |
| `punch(id)` | 被打中一样挤压回弹 | 结论已经在画面上，再"砸"一下 |
| `shake(id)` / `shake()` | 元素左右摇（不对）/ 镜头震一下（撞击） | 否定 / 落地、盖章 |
| `wiggle(id)` / `jump(id)` | 摆动 / 跳起落下 | 俏皮的强调 |
| `glow(id, hold=True)` | 主色光晕（可常亮） | 最后要记住的东西 |
| `flash(id)` | 闪一下亮 | 数字更新 |
| `out(id, 'fade'|'drop'|'shrink'|'blur'|'up'|'left'|'right'|'zoom'|'cut')` | 退场，之后保持消失 | 推翻旧说法、腾地方 |
| `move(id, dx, dy, s=, rot=, op=, curve=)` | 移动 / 缩放 / 旋转 / 变淡，之后保持 | 重新排版、腾位置；`curve='arc'` 走弧线，`'spring'` 过头回弹 |
| `dim(id)` / `undim(id)` | 变淡 / 恢复 | |
| `focus(id, ...)` / `unfocus()` | 这一页其他东西都退到背景 / 恢复 | 讲到某一条 |
| `loop(id, 'float'|'breathe'|'spin')` | 一直轻轻动，直到换页 | 图标、加载圈；少用，它会让画面停不下来 |
| `cursor(id, x, y)` + `go(id, x, y)` + `click(id, target=)` | 鼠标出现、滑过去、按下（涟漪 + 目标按下去） | 产品操作、"点一下就……" |

同一个元素上的多个动作会叠加（一边移动一边发光没问题）。一个动作对象只能用一次。

## 镜头

- **推近**：`s.beat(..., cam=(x, y, 倍数))`，第 4 项可选曲线 `'smooth'`（默认）、`'whip'`（快甩）、`'snap'`（快到再停稳）、`'slow'`；`cam=0` 回全景。
- **震动**：show 里放 `shake()`，镜头按撞击衰减地震一下，自动配闷响。
- **一镜到底**：`Slide(world=(宽, 高), cam0=(x, y, 倍数))`，内容摆在比屏幕大的画布上，镜头在上面移动；大画布上倍数可以小于 1 看全貌。静态页会显示整块画布。

## 换页（`Slide(trans=...)`）

| 写法 | 效果 | 算衔接吗 |
|---|---|---|
| `fade` / `push` / `up` / `zoom` / `wipe` / `cut` | 淡入淡出 / 横推 / 竖推 / 缩放 / 擦除 / 硬切 | 不算，是换页 |
| `('iris', x, y)` | 从 (x, y) 圆形展开新页 | 算：新的从旧的某一点打开 |
| `('through', id)` | 镜头推进上一页的某个元素，穿过去就是新页 | 算 |
| `'magic'` + `carry={旧id: 新id}` | 元素从上一页飞到新位置、变成新大小 | 算 |

## 声音

元素和动作自动配音效，少而准：弹出 pop、框 tone、柱子上行琶音、表格行 wipe、高亮框 swish、红叉 wrong、换页 whoosh、`punch` 撞击、镜头 `shake()` 闷响、`click` 点击、`staccato` 嘀嗒、`prompt` 键盘声。可选音效：`'chime'`（关键结论）、`'impact'`、`'thud'`、`'tick'`、`'whip'`、`'riser'`（放在揭晓之前，结束在揭晓那一刻）。任何元素或动作 `sfx=None` 静音。

配乐 `META['bgm']`：`True`（lo-fi，讲解默认）、`'pulse'`（112 BPM 推进型，宣传片）、用户自己的音乐文件路径、`False`。有口播时音乐比人声低约 24 dB（没征得用户同意不要调大），无口播时音乐是主角。

## 连续动画（场景）

入场和动作只能让元素出现或动一下。原理动画、情感短片需要**一直在变**的画面，比如镜头移动、波形变形、粒子流动、光慢慢变暗，这些写在场景里：

```python
s.animate('''S => {
  S.cam(S.el('w'), [[0, 570, 445, 1.5], ['b1', 960, 540, 1.0, 1.8]], 5);   // 镜头：先贴近代码，第二句拉远
  S.stroke(S.el('rib'), S.p(S.word('b1', '配音', -.3), .9));               // 说到「配音」时画出一条线
  S.soft('card', S.p(S.word('b1', '配音', .4), .7));                       // 卡片落定
}''', setup=None)
s.sound('b1', 'swish', word='配音', off=-.3, d=.9)                         // 场景动作的音效要自己放
```

| 写法 | 作用 |
|---|---|
| `S.t` / `S.d` / `S.t0` | 这一页开始后的秒数、这一页时长、这一页在成片里的起点。静态图里 `S.t = 1e4`，也就是所有动作都已完成 |
| `S.at('b2')` / `S.at('open+0.3')` / `S.word('b2', '配音', off)` | 第几句开始的时刻（也可以用 `beat(key='open')` 起的名字）；说到某个词的时刻 |
| `S.p(时刻, 秒数, 曲线)` / `S.since(时刻)` | 0→1 的进度（默认 cubicInOut）/ 从某刻起过了多久 |
| `S.cam(世界元素, [[时刻, x, y, 倍数, 时长, 曲线], …], 晃动)` | 镜头在大画布上移动，各段之间平滑衔接；晃动是手持感的像素数 |
| `S.set(el, {x, y, s, sx, sy, r, o, blur, origin})` | 一次设定位置、缩放、旋转、透明度、模糊 |
| `S.soft(el, k, dy)` / `S.line(el, 进, 出)` | 慢慢落定（淡入、上浮、对焦）/ 一行字对焦浮现 1.6 秒、退场 1 秒 |
| `S.stroke(path, k)` / `S.along(path, u)` / `S.morph(path, d0, d1, k)` | 描线 / 路径上某处的坐标和方向 / 两条命令相同的路径之间形变 |
| `S.scaleY(bar, v)` | 波形柱、电平条的高度 |
| `S.ctx(canvas)` / `S.dust(canvas, n, 种子, 范围, 'r,g,b')` | 清空的 2D 画布 / 光里的浮尘 |
| `S.noise(x, 种子)` / `S.hash(i, j)` | 平滑漂移 / 固定的随机数。**不要用 `Math.random()`**，每一帧必须只由时间决定 |
| `S.chars('b4')` | 这一句每个字在第几秒，可以把真实时间印在画面上 |
| `s.sound(句, 种类, word=, off=, d=)` | 场景动作的小音效：tone、pop、chime、tick、swish、wipe、whoosh…… |

- 画图部件 `engine/kit.py`：`box`、`text(center=)`、`editor`（带高亮条和光标的代码窗）、`bars` + `speech_env`（波形）、`grid`（点阵）、`glow`（柔光）、`svg`。
- 胶片效果：`use_theme(grain=0.07, vignette=0.22, letterbox=2.39, drift=0.03)`，分别是颗粒、暗角、遮幅和每页缓推。单页可以写 `Slide(drift=0)` 关掉缓推。
- 有场景的页每一帧都要截图，渲染比讲解片慢几倍。只给真正在动的页加场景。

## 量一量（出片前）

- `studio <名字> stills` → `layout.txt`：出界、重叠、溢出、压字幕。
- `studio <名字> silent` / `rhythm` → `rhythm.txt`：每页长短变化、换页有几次衔接、静止占比、最长一直在动多久。
- `studio ref 视频.mp4`：拆参考片，也可以量自己的成片对比。


## 配方

新做出一个好用的组合，就加在这里。照抄后按内容改坐标和时间。

**用同一个物件讲价格变化**：凭证卡片写未来付款，价格牌单独出现；下一页 magic carry 同一凭证，只改变要求收益率；再下一页 carry 凭证，旧价格牌 out、新价格牌出现并稍下移。固定金额始终不变，移动表达价格方向；不要让数字在变形转场中串到另一种含义。

**结论砸下来**：`title('t', '结论', a='zoom')` + `(shake(), 0.25)`；或者已经在画面上的结论 `punch('t')`，重要的加 `sfx='chime'`。

**数字揭晓**：`stat('n', '<em>10.06</em><small>倍</small>', '说明')` 默认滚动；讲到它时 `cam=(x, y, 1.4)` 推近，讲完 `cam=0`。

**聚焦一条**：一页三条要点，讲到第二条时 `(focus('p1'), 0.3)`，讲完 `unfocus()`。

**推翻误区**：`txt('a', f'很多人以为{strike("st", "越便宜越好")}')` → `('st', 1.2)` 划掉 → 下一句 `out('a', 'drop')` + 新说法 `rise` 入场。

**上一页的结论变下一页的标题**：下一页 `Slide(trans='magic', carry={'上一页结论id': '本页标题id'})`。

**从刚讲到的东西展开下一页**：`trans=('iris', 那个元素中心 x, y)`，或者 `trans=('through', '元素id')` 推进去。

**一镜到底讲流程**：`Slide(world=(2*W, H), cam0=(W/2, H/2, 1))`，左边第一站、右边后几站；一拍 `cam=(下一站, 1, 'whip')` 甩过去，最后 `cam=(W, H/2, 0.56, 'snap')` 拉远看全貌，加 `shake()`。

**产品操作演示**：`prompt('p', '...')` 打字 → `cursor('m', x, y)` 出现 → `go('m', 按钮x, 按钮y)` → `click('m', target='p')` → 下一拍结果出现（或 `magic` 把输入框变成结果窗口）。

**连击**：`s.beat(None, s.staccato('w', ['写稿。', '配音。', '出片。'], 400, gap=B), dur=3 * B)`，`B` 是一拍。

**字标落版**：`kinetic('logo', 'video-studio', y, mode='letters')` → `(punch('logo'), 0.95)` + `(shake(), 0.95)` → 标语 `kinetic(..., mode='words')`。

**转折前留一口气**：结论前插一个无声节拍 `s.beat(None, [], dur=0.6)`。

**讲着讲着让图标活一点**：`loop('icon', 'float')`，一页最多一个。

**屏幕上的代码就是正在念的这句**（讲"视频即代码"）：代码卡片里写这一页的 `s.beat('…')`，字符串和口播逐字相同；一个浅底高亮条放在那一行后面，念到下一句时 `move('bar', dy=行高)` 移过去，念完 `out('bar')`。手写批注「高亮的这行 = 正在念的字幕 ↓」。

**真实时间戳演示**：一排方块，每块一个字和它在成片里的出声时刻，方块在那个字念出来时弹出。时间不手填：`check` 之后跑一个小脚本，从 `work/tts/*.json` 的 events（逐词时间）和 `work/plan.json` 的句子起点算出来，写进 `data/timestamps.json`，episode 读它；改了那句口播要重跑脚本。

**修好了，用数说话**：`bars(s, 'b', [('修之前', v0, T.muted), ('修之后', v1)], ...)`，旁边一行写量法、一行写代价，数都从 `data/*.json` 读。口播按"修之前……修之后……代价是……"三拍说。量法要单独写出来：用修复本身的标准去量，结果几乎一定好看（见 fact-check.md）。

**全景图再逐步展开**：一页摆出全部步骤框，按"几步、哪几步谁做"分组画线；下一页 `trans=('iris', 第一个框中心 x, y)` 从第一步展开，后面各页用 `tag('第 N 步')` 接上。

**只属于这一期的样式**：在第一页 `s.add('<style>…</style>')` 里写，整份 deck 都能用，不用动主题的 css。封面是单独的页面，用不到这里的样式。

**真截图放进手机框，镜头推近讲界面**：截图按 3 倍截（1170 宽）。在 episode.py 里写一个小的 `Phone` 类（画手机框、放截图），带一个 `at(px, py)` 把截图上的像素换算成画布坐标。框住按钮用 `s.mark(*框的位置, color=T.ink)`，推近用 `cam=(540, ph.at(0, py)[1], 1.6)`，光标点按钮用 `go(..., *ph.at(px, py))`。只要截图里的一块，就写个 `crop()` 裁成白卡片：两张面板上下摆、各盖一个章，比两部手机并排清楚。推近的页要 `wm=False`。

**用产品 Logo 讲规则**：如果 Logo 本身是个图形（比如一圈棋盘格、右上角一格跳出圈），就让讲解的动作最后正好变成 Logo：棋子在这一圈上一格格跳讲规则，达成目标的那一刻所有格子变色、那一格跳出去，整个画面正好变成 Logo。结论和品牌在同一个动作里出来。

### 原理动画：一行代码长出三层，再合成一帧

1. 代码一行行打出来。
2. 讲到这一行时，高亮条扫过，代码窗退到左边。
3. 右边从斜上方看下去，叠着三张平面：画面、字幕、配音，用的是 CSS 3D，`rotateX(56deg) rotateZ(-38deg)` 加 `translateZ`。说到哪个词，哪一层就升起来，同时右侧引出一根标签线。
4. 下一句时三层旋回正面、压平，合成一帧，下面再落标题。

开场一次就把「视频 = 画面 + 字幕 + 配音」讲清楚了。

### 原理动画：一句话分成两条带子

代码里那句口播的字符串，用两条贝塞尔带子分别连到「配音」波形和「字幕」条，各自在说到这个词时画出来。画完以后，带子上一直有光点流动，用 `S.along`。另一条带子从列表连到画面上的卡片。

### 原理动画：划掉旧说法

1. 放大镜从核查者身边出发，滑到旧句子上。
2. 那几个字变成珊瑚色，再划一道删除线。
3. 下面淡入正确的说法，最后画一个青绿色的勾。

用来讲「改过什么」很直观。

### 原理动画：同一个东西换状态

同一排波形柱，用 `S.scaleY` 在两组包络（`ENV_OLD` → `ENV_NEW`）之间插值。中间某处标记从珊瑚色（有问题）变成钴蓝（修好）。讲修复前后的对比，用同一个东西变形，比左右两张图更有说服力。

### 原理动画：相同的帧叠成一摞

帧卡片从浏览器右边一张张出来，排成传送带。讲到「画面不变」时收成一摞，标上「×12」；讲到「一直在动」时，又展开成每张都不同的一排。

### 情感短片：散开的词聚成一行

1. 一组术语像星星一样散在夜空里，轻轻漂移、明暗呼吸。
2. 说到「一个词、一个词」时，它们逐个被点亮，加暖色光晕。
3. 说到「慢慢弄明白」时，它们汇成一行。

### 情感短片：一盏灯关上

1. 开场是暖色台灯，有一道光锥，光里有浮尘。
2. 说到某个转折词时，暖光慢慢褪成冷蓝，浮尘也淡下去。
3. 文字颜色随底色从深变浅，问句用大号浅色字浮现。
