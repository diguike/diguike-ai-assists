# 宣传片 / 发布片 / 预告（无口播，跟着音乐走）

10～60 秒，给一个产品、一个项目、一个栏目、一期视频做的动效短片。没有口播，画面跟着音乐的节拍走；靠大字、元素之间的衔接、镜头运动讲一件事。

- 模板：`studio new <名字> '标题' --kind promo`（16:9；竖屏加 `size=(1080, 1920)` 后重排版）。模板本身是一个概念（"一句话变成一条视频"），**不要套它的情节**，只借它的写法。
- 动作和配方：`references/atoms.md`。

方法借鉴开源项目 onetake（做产品动效短片的 skill）。它总结的核心问题是：大多数 AI 和模板做的动效片是"散的"，一个画面替换掉上一个，节奏再好也像翻 PPT。解决办法是：**每次换画面，都有一个东西活下来，看得见地变成下一个画面**；节奏要有长有短，有停有爆发。

## 流程

### 1. 有参考片先拆参考（有就必做）

```bash
studio ref 参考.mp4            # -> ~/VideoStudio/work/ref/<名字>/：energy.txt、summary.json、palette.png、sheet_*.jpg
```

读几个数：静止占多少（好的片子常常 1/3 时间几乎不动）、剪辑点几个、在哪里爆发、最长一段安静多久；配色给出的 `use_theme()` 建议；样张里元素占画面多大、主体怎么动。**学它的规则，不学它的情节**：参考片的镜头顺序照搬没有意义，要找的是"它每个东西都遵守的那条规则"，用到自己的主题上。

### 2. 三个概念，用户选一个

概念是**一句关于画面的话**，不是关于产品的话。三个概念的核心想法要不一样，不能是同一套卡片换三种讲法。例如：
- **一个元素变成一切**：一个光标闪烁 → 变成输入框 → 展开成流程 → 收成字标；
- **一个镜头穿过所有尺度**：从一个像素拉远到整个界面，或者推进一张卡片里就是下一个场景；
- **连锁反应**：每个画面都是撞上上一个画面才开始的；
- **前后对比**：左边是散的 PPT 式，右边是接起来的，最后右边吞掉左边。

每个概念写清楚：开头那一帧、每次换画面靠什么接、它不用什么（不用卡片？不用硬切？），以及它的**风格**（预设、配色、字体，见 style.md）。给用户选。

### 3. 节拍表：节奏和衔接一起写

先定音乐速度（`META['bpm']`，内置配乐 `'pulse'` 默认 112），然后写表：

| 时间（拍 / 小节） | 画面 | 什么在动 | 什么不动 | 靠什么接到下一拍 |
|---|---|---|---|---|

- **长短差 4 倍以上**：0.25 秒的字和 2 秒的停留放在一起。镜头长度全一样就是节拍器。
- **至少一段近乎静止**（画面和声音都安静），**至多一两处爆发**（`s.staccato()` 连续硬切的大字、一串弹出）。
- **每个换画面的地方都写明接法**：同一块大画布上镜头移过去（`world=` + `cam=`）、元素飞到下一页（`magic` + `carry`）、推进一个元素里（`('through', id)`）、从主体圆形展开（`('iris', x, y)`）、光标点了按钮结果出现（`click()` + 下一拍）。只有爆发段和最后落版可以硬切。

### 4. 写 episode.py

- `META = {'voice': None, 'bgm': 'pulse', 'bpm': 112}`：没有口播，每个节拍 `s.beat(None, [...], dur=拍数 * B)`，`B = 60 / BPM`。节拍时长精确相加，换页正好落在小节上。
- 配乐：内置 `'pulse'`（112 BPM 推进型）或 `True`（lo-fi 电钢琴）；用户自己的音乐写路径 `'assets/xx.mp3'`。**只用用户提供并有权使用的音乐**，不要自己去找有版权的曲子。无口播时音乐是主角，`music_lu` 调它和音效的平衡（默认 -3）。
- 一镜到底：`Slide(world=(宽, 高), cam0=(x, y, 倍数))`，每拍 `cam=(x, y, 倍数, 'whip'|'snap'|'smooth'|'slow')`；落地时 `shake()`。大画布上 `x=None` 是按整块画布居中，要放在某一屏就写 x 和宽度。
- 原因要看得见：产品操作用 `cursor()` + `go()` + `click(target=)`，别让界面自己变。
- 字：大字用 `kinetic()`（`letters` 做字标、`words` 做口号、`lines` 做两行标语），连击用 `s.staccato()`。

### 5. 先看再出

```bash
studio <名字> silent     # 几秒钟出无声动画 + 节奏报告（rhythm.txt）
studio <名字> stills     # 每页最终状态 + layout.txt
studio <名字> all        # 带音乐和音效的成片（20 秒片约 10 秒）
studio ref ~/VideoStudio/episodes/<名字>/out/<名字>.mp4   # 用拆参考片的同一把尺子量自己的片子，和参考对比
```

## 硬规则

- **不要默认套模板的情节**。三个核心想法不同的概念，用户选。
- **不要把上一条片子的风格带到下一条**。配色、字体、镜头语言、转场在概念阶段重新选。
- **不要像节拍器**：镜头长短要有变化（节奏报告里的变化系数 ≥ 0.25）。
- **不要替换，要衔接**：两页之间什么都没留下就是翻页。节奏报告里"有衔接"的换页应该占大多数。
- **要有停顿**：好的片子大约三分之一时间几乎不动。镜头推近也算动，停顿就是真的停。
- **小元素，大留白**：画面大部分是底色，满屏的东西只出现在一两个停留镜头里。
- **原因要看得见**：光标点了，东西才出来；撞上了，才弹开。
- **不要粒子、彩纸、闪光点**：一看就是模板。需要点缀时让字自己带一点挤压回弹（`punch()`）。
- **声音少于事件**：不是每个元素都要响。同一种材质，落点的地方最响。

## 经验（每做完一条，把用户反馈和踩到的坑记在这里）

- （来自 onetake 的案例）一条节奏完美的片子仍被评价"像 PPT"，原因是每拍都替换上一拍；改成每拍从上一拍长出来才通过。
- （来自 onetake 的案例）给每个事件都配一个合成提示音，被评价"低劣"；音效要少，要像在同一个空间里。
- 大画布上居中的元素会按整块画布居中，要放在某一屏得写 x 和宽度。
