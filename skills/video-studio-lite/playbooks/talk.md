# 大字口播 / 文字快闪（竖屏，Edge 配音 + 大字动效）

30 秒～3 分钟的竖屏短视频：没有真人出镜，Edge TTS 在讲，屏幕上是这句话最关键的几个字，字很大，重点词被"打"一下。适合一个知识点、一个观点、一个反常识。

- 模板：`studio new <名字> '标题' --kind talk`（1080×1920，关掉了底部字幕，`META['subs'] = False`）。
- 动作和配方：`references/atoms.md`。真人出镜的口播（拍摄素材 + 字幕 + 剪气口）还不支持。

## 结构

1. **3 秒钩子**：一个问题或反常识，大字逐词弹出（`kinetic(mode='words')`）。
2. **一屏一个意思**：每页只放这句话的关键短语，一行不超过 8 个字，最多两三个元素。
3. **数字单独一屏**：`stat()` 从 0 滚上来；两个数字比较时，后一个出来时 `focus()` 它。
4. **转折前留一口气**：结论之前加一个无声节拍 `s.beat(None, [], dur=0.6)`，然后结论 `pops` / `zoom` 弹出，加 `punch()` 或 `shake()`。
5. **误区用删除线**：`strike()` 划掉旧说法，再给新说法。
6. **最后一屏是要记住的那句**，语速放慢（`rate='+12%'`），`glow(hold=True)`。
7. 片尾：一句行动号召，或 `end_slide()`（默认「下期见」，`end_card` / `outro` 可换）。

## 画面规则

- 字幕关掉，大字就是字幕。内容放在 y≈300～1400：底部 20% 和右侧会被平台按钮挡住。
- 大字 110～190px，用粗黑一类字体（模板是 `typeset='heavy'`，轻量版用系统最粗的黑体：Mac 苹方、Windows 微软雅黑）。全片只有一个重点色。
- 换页方式要跟内容有关：从刚盖章的标题圆形展开（`iris`）、推进那个数字里（`through`）、结论缩放进来（`zoom`）。不要连续五次同一种。
- 每页都有一个"被打一下"的词：荧光笔 `hl()`、`punch()`、`glow()`，三种轮着用，不要全片都 `shake()`。
- 镜头推近只在结论那一下用。

## 声音

- Edge TTS（默认云希 `+22%`），`studio <名字> check` 看 `lint.txt`。数字最容易念错，比如"12年"会被当成年份念成"一二年"，要写 `tts='十二年'`。
- 背景音乐和讲解视频一样要很低（比人声低约 24 dB），没征得用户同意不要调大。

## 经验（每做完一条，把用户反馈和踩到的坑记在这里）

- 单独的"12年"被念成"一二年"，用 `tts=` 改念法。数字念法要自己对着稿子扫一遍，lint 不一定抓得到。
- 竖屏大字容易全挤在上半屏，排完先看 `stills`，内容整体往下放一点。
- 给自己的产品做推广：大字口播的写法加上真截图，开底部字幕（`subs=True`）。产品界面不重画，直接截真页面：
  - **截图**：Playwright 开手机视口 390×844、`deviceScaleFactor: 3`，截出 1170×2532。放进 560 宽的手机框，镜头推近到 1.6–1.75 倍还是清楚的。截图脚本放在临时目录，episode 的 `assets/` 里只放选中的截图（JPEG 质量 86，每张约 250 KB）。
  - **要拍到动态过程**（比如 AI 在想、在说理由）：每 0.7 秒截一张，每 10 帧记一次页面文字（`innerText`），按页面上的提示文字找时间点挑帧。要花钱或碰线上数据的操作，先问用户。
  - **镜头推近截图时关水印**（`Slide(wm=False)`）：角上的签名会压在推近后的截图上。
  - **一页里几个 `dim()`/`out()` 不写时间会依次排队**，最后一个要等好几秒才动。要同时变暗，写成 `(dim(x), 0)`。
  - **英文名的 `tts=` 用小写**：大写的英文名可能被逐个字母念出来，改成小写就念成单词了。网址写成 `xxx 点 app` 这样的念法。
  - 核查 agent 在推广片里常抓到两类要命的问题：一是"去搜 XX"，搜出来的前几条可能是别的东西（新域名也可能还没被收录），改成"记不住网址就截个图"；二是引用的 AI 输出本身算错了，原稿还在夸它。如实点破，反而是最有料的一句。坑记在 fact-check.md「推广自家产品」。
